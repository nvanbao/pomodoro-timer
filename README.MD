# pomodoro-timer

Đồng hồ Pomodoro viết bằng HTML, CSS và JavaScript thuần.

## Tính năng
- 3 chế độ: tập trung, nghỉ ngắn, nghỉ dài (mặc định 25/5/15 phút)
- Tùy chỉnh thời lượng từng chế độ, lưu trong trình duyệt
- Bắt đầu, tạm dừng, đặt lại, thanh tiến độ
- Tự chuyển sang giờ nghỉ khi hết giờ tập trung (nghỉ dài sau mỗi 4 phiên)
- Âm báo khi hết giờ (có thể tắt)
- Hiển thị thời gian còn lại ngay trên tiêu đề tab
- Đếm số phiên hoàn thành trong ngày
- Chạy đúng giờ kể cả khi tab bị ẩn
- Phím tắt: `P` hoặc `Space` bật/tắt, `R` đặt lại, `1` `2` `3` đổi chế độ
- Cảnh báo khi đóng tab lúc đang đếm
- Giao diện tối theo cài đặt hệ thống

## Cách chạy
Mở file `index.html` bằng trình duyệt.
